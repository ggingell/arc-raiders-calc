Compression Ratio Explanation

Equal to 1: Crafting the output will use the same number of inventory slots for both the input and output. Example: Epic tier Augment (1)

Greater than 1: Crafting the output will reduce the total inventory slots used. Example: Mechanical Components (2)

Less than 1: Crafting the output will increase the total inventory slots used. Example: Raider Hatch Key (0.8)
